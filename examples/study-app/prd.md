# PRD: 스터디 찾기와 참여 신청 (v0.3)

> 테스트용 가상 서비스 "모각코 메이트"의 PRD 일부

## 1. 배경

동네에서 함께 공부할 사람을 찾기 어렵다. 지역을 기준으로 모각코(모여서 각자 코딩) 스터디를 찾고 참여 신청하는 기능을 만든다.

## 2. 대상 사용자

혼자 공부하다 동기 부여가 필요한 대학생과 취업 준비생

## 3. 기능

### 3.1 홈
- 내가 참여 중인 스터디 목록을 보여준다.
- 스터디 카드에는 이름, 다음 모임 날짜, 참여 인원을 표시한다.
- 참여 중인 스터디가 없으면 "아직 참여한 스터디가 없어요" 문구와 [스터디 찾기] 버튼을 보여준다.

### 3.2 스터디 검색
- 키워드와 지역(구 단위)으로 검색한다.
- 결과는 최근 등록순으로 정렬한다.

### 3.3 스터디 상세
- 스터디 소개, 모임 장소, 요일과 시간, 현재 인원과 최대 인원, 방장 프로필을 보여준다.
- 하단에 [참여 신청] 버튼을 둔다.

### 3.4 참여 신청
- 신청하면 방장이 승인해야 참여가 확정된다. (승인제)
- 신청할 때 한 줄 자기소개(최대 50자)를 쓴다.
- 스터디의 최대 인원은 10명이다.

### 3.5 스터디 만들기
- 입력 항목
  - 스터디 이름: 필수, 최대 20자
  - 소개: 필수, 최대 300자
  - 지역: 필수
  - 요일과 시간: 필수
  - 최대 인원: 2~10명
  - 대표 이미지: 선택
- 만들기를 마치면 만든 스터디의 상세 화면으로 이동한다.
