# PRD 반영: 스터디 찾기와 참여 신청

> 반영한 답: Q1 C, Q2 A, Q3 A, Q4 B, Q5 C, Q6 B | 보류: Q7

## PRD에 붙일 정책

### 3.1 홈에 추가
- 참여 중인 스터디와 함께, 승인을 기다리는 스터디도 "승인 대기" 표시를 붙여 보여준다.
- 승인되면 "승인 대기" 표시를 떼고 참여 중인 스터디로 보여준다.
- 결정: Q2 A

### 3.2 스터디 검색에 추가
- 인원이 다 찬 스터디도 검색 결과에 보여주고 "모집 마감"으로 표시한다.
- 결정: Q4 B
- 검색 결과가 없으면 "검색 결과가 없어요" 안내와 [스터디 만들기] 버튼을 보여준다.
- 결정: Q5 C

### 3.3 스터디 상세에 추가
- 현재 인원이 최대 인원과 같으면 "모집 마감"으로 표시하고 [참여 신청] 버튼을 비활성으로 둔다.
- 결정: Q4 B
- 방장에게는 [참여 신청] 대신 [신청 관리] 버튼을 보여준다. [신청 관리]에서는 받은 신청 전체를 보고 승인하거나 거절한다.
- 결정: Q1 C

### 3.4 참여 신청에 추가
- 방장이 거절하면 신청한 스터디에 "거절됨"을 표시한다. 거절된 사람은 같은 스터디에 다시 신청할 수 있다.
- 결정: Q3 A

### 새 절 제안: 3.6 알림
- 새 신청이 들어오면 방장에게 알림을 보낸다. 알림을 누르면 그 신청자의 한 줄 자기소개와 [승인], [거절] 버튼을 보여준다.
- 결정: Q1 C
- 짚을 점: Q1 C는 리포트에서 "새 기능 필요"로 표시한 선택지다. 지금 PRD에는 알림 기능이 없으므로 이 절을 새로 넣어야 하고 개발 범위가 늘어난다.

### 새 절 제안: 3.7 로그인
- 로그인하지 않아도 스터디 검색과 상세를 볼 수 있다.
- 로그인하지 않은 사람이 [참여 신청]을 누르면 로그인을 요청한다.
- 결정: Q6 B
