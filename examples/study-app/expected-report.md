## 기획자에게 묻는 질문

답하는 법: `Q1 B, Q2 A, Q3 직접: ...`처럼 번호와 선택지를 보내 주세요.

### Q1. 방장은 들어온 참여 신청을 어디서 보고 승인하나요?
- 관련 화면: F4 스터디 상세, (승인 화면 없음)
- 왜 지금 정해야 하나: PRD 3.4는 승인제인데 승인하는 화면과 흐름이 없어서, 참여 신청이 끝까지 동작하지 않아요.
- A) 상세에서 방장에게만 [신청 관리] 버튼: 누르면 신청자 목록이 나오고 한 명씩 승인하거나 거절
- B) 알림에서 바로 처리: 신청 알림을 누르면 그 사람의 자기소개와 [승인], [거절] 버튼 (새 기능 필요: 알림)
- C) A와 B 둘 다: 알림으로 바로 처리하고, 놓친 신청은 [신청 관리]에서 다시 확인 (새 기능 필요: 알림)
- 직접 입력
- 추천: A. [H6] 방장이 자기 스터디를 관리하러 가장 먼저 여는 곳이 상세라 따로 기억할 곳이 없어요. 새 신청을 바로 알리려면 알림 기능이 새로 필요해서 B와 C는 범위가 늘어나요.

### Q2. 참여 신청을 보내고 승인을 기다리는 동안, 신청한 사람에게 무엇을 보여줄까요?
- 관련 화면: F1 홈, F4 스터디 상세
- 왜 지금 정해야 하나: PRD 3.1 홈은 "참여 중인" 스터디만 보여줘서, 신청만 한 스터디는 어디에서도 다시 볼 수 없어요.
- A) 홈에 함께 보여주기: "승인 대기" 표시가 붙은 카드로 참여 중인 스터디와 같이 보임
- B) 상세에서만 보여주기: 홈에는 없고, 그 스터디 상세에 들어가야 버튼이 "승인 대기 중"으로 보임
- C) 마이 탭에 신청 내역: 마이 탭에 보낸 신청 목록을 따로 둠
- 직접 입력
- 추천: A. [H1] 내가 보낸 신청이 어떻게 됐는지 바로 보여야 같은 곳에 또 신청하거나 기다리다 떠나지 않아요.

### Q3. 방장이 신청을 거절하면 신청한 사람은 어떻게 되나요?
- 관련 화면: F1 홈, F4 스터디 상세
- 왜 지금 정해야 하나: 거절 결과를 보여줄지, 다시 신청을 받을지에 따라 신청 데이터 구조와 상세 버튼이 달라져요.
- A) 거절 표시, 다시 신청 가능: 신청한 스터디에 "거절됨"이 표시되고, 원하면 같은 스터디에 다시 신청
- B) 거절 표시, 다시 신청 불가: 신청한 스터디에 "거절됨"이 표시되고, 그 스터디 상세의 신청 버튼은 비활성
- C) 표시하지 않음: 승인 대기 표시가 조용히 사라짐
- 직접 입력
- 추천: A. [H9] 결과를 알려야 다른 스터디를 찾으러 갈 수 있어요. 같은 사람의 반복 신청이 걱정되면 B를 고르세요.

### Q4. 인원이 다 찬 스터디(10/10명)는 어떻게 보여줄까요?
- 관련 화면: F3 검색, F4 스터디 상세
- 왜 지금 정해야 하나: 최대 인원(PRD 3.4)은 정해져 있지만 다 찼을 때 검색과 신청이 어떻게 되는지 없어요.
- A) 검색에서 숨기기: 다 찬 스터디는 검색 결과에 나오지 않음
- B) 마감으로 보여주기: 검색 카드에 "모집 마감" 표시, 상세의 [참여 신청] 버튼은 비활성
- C) 마감 표시와 자리 알림: B에 [자리 나면 알림 받기] 버튼 추가 (새 기능 필요)
- 직접 입력
- 추천: B. [H1] 마감 상태를 보여줘야 사용자가 헛걸음하지 않아요. C는 알림 기능이 새로 필요해서 이번 범위를 넘어요.

### Q5. 검색 결과가 없으면 무엇을 보여줄까요?
- 관련 화면: F3 검색
- 왜 지금 정해야 하나: 동네 단위 검색이라 결과가 없는 경우가 자주 생기는데, 그때 화면이 없어요.
- A) 안내만: "검색 결과가 없어요" 문구
- B) 다른 지역 제안: 안내와 함께 [옆 동네까지 찾기] 버튼 (새 기능 필요)
- C) 직접 만들기 제안: 안내와 함께 [스터디 만들기] 버튼
- 직접 입력
- 추천: C. [H9] 원하는 스터디가 없을 때 직접 만드는 길을 열어 주면 그냥 떠나는 대신 다음 행동이 생겨요.

### Q6. 로그인하지 않은 사람도 스터디를 검색하고 상세를 볼 수 있나요?
- 관련 화면: F3 검색, F4 스터디 상세, F5 참여 신청
- 왜 지금 정해야 하나: PRD에 로그인 정책이 없어서, 로그인하지 않은 사람이 [참여 신청]을 눌렀을 때의 화면을 그릴 수 없어요.
- A) 처음부터 로그인: 앱을 열면 로그인부터 해야 함
- B) 둘러보기 허용: 검색과 상세는 볼 수 있고, [참여 신청]을 누를 때 로그인 요청
- C) 검색만 허용: 검색 목록까지만 보이고, 상세를 열 때 로그인 요청
- 직접 입력
- 추천: B. [H3] 둘러보고 마음이 생겼을 때 가입하게 하면 처음 들어올 때 부담이 줄어요.

### Q7. 스터디를 만들다가 화면을 나가면 쓰던 내용은 어떻게 하나요?
- 관련 화면: F7 스터디 만들기
- 왜 지금 정해야 하나: 소개를 300자까지 쓰는 화면이라 실수로 나가면 손실이 커요. 저장 여부에 따라 개발 범위가 달라져요.
- A) 확인 창: 나가려고 하면 "작성 중인 내용이 사라져요" 확인
- B) 임시 저장: 자동으로 저장하고, 다시 들어오면 이어 쓰기
- C) 그냥 사라짐: 별도 처리 없음
- 직접 입력
- 추천: A. [H3, H5] 실수로 나가는 것을 막을 수 있고, B보다 개발 부담이 작아요.
